# htool 网页首启与恢复

适用镜像为带 htool 的 F1 Ubuntu 和 Armbian Rockchip USB 直刷固件。首启需要一条网线直连电脑和 F1 的管理口。管理口使用 `eno1` 的静态地址 `192.168.55.1/24`，路由器侧网口不接受首启注册。

## 设置设备

1. 在电脑的直连网口设置 `192.168.55.2/24`，网关留空，打开 `https://192.168.55.1:80`。HTTPS 证书由设备自己生成，确认直连设备身份后再继续。
2. 第一页设置系统管理员 `root` 的密码，第二页设置普通用户名和密码。最后一个按钮提交两组设置。
3. 使用完成页的 SSH 命令和普通用户密码。执行 `su -` 并输入管理员密码即可进行系统管理。

用户名使用 3–32 个字符，从小写英文字母开始，可用小写字母、数字、下划线和连字符。两组密码均使用 12–72 个可见 ASCII 字符，大小写和标点可以混用，且必须不同。

## 排查与恢复

- 页面打不开时，先核对网线、管理口、电脑 IPv4 和浏览器地址。已有本地管理权限时，可用 `ip -br addr` 和 `systemctl status htool-web.socket htool-account.socket` 核对配置。
- 提交中断后刷新页面。若设备显示有待恢复的用户名，重新填写两组密码并提交。后台会核对已创建账号是否属于本次初始化。
- 设置完成后，网页仅显示登录指引。在正常使用中重置密码需要通过已有本机管理权限操作，或采用 [Rockchip 固件恢复流程](../README.md#刷机前准备)。手动删除状态文件可能造成不完整的设备状态。
- Go 测试和镜像打包通过后，两种镜像仍需分别确认：管理口可以注册、路由器侧网口无法注册、普通账号可 SSH、`su -` 可用、重启后注册保持锁定。

htool 由 systemd 恢复进程。整机硬件看门狗的配置属于 BSP 和系统管理，与首启网页独立。
